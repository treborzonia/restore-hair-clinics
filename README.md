# Restore Hair Clinics — Private Redesign Concept

Private redesign concept for Restore Hair Clinics by Dr Raghu Reddy (Harley Street, London). Not affiliated with or endorsed by the clinic.

Built with Next.js (App Router), TypeScript, and Tailwind CSS.

## Commands

- `npm run dev` — local dev server
- `npm run build` — production build
- `npm run lint` — ESLint

See `CLAUDE.md` for project instructions and `reference/` for research and decision logs.
